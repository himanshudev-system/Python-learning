## 💻 How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/himanshudev-system/Python-learning.git
   ```

3. Open the repository folder in your terminal.
4. Run a Python file:

   ```bash
   python3 filename.py
   ```

   Replace `filename.py` with the name of your Python file.
